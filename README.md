# codsoft_3
# Iris Species Classification

This project was completed as part of my Data Science internship at **CodSoft**. It demonstrates classification of Iris flower species using multiple machine learning algorithms with proper preprocessing and evaluation techniques.

## Dataset

The dataset used is the well-known Iris dataset, which contains 150 rows and 5 columns:

- `sepal_length`
- `sepal_width`
- `petal_length`
- `petal_width`
- `species` (target variable)

## Exploratory Data Analysis (EDA)

- **Count Plot**: Visualized species distribution using Seaborn.
- **Pair Plot**: Displayed relationships between features, colored by species.
- **Correlation Heatmap**: Showed correlations between numerical features.

## Preprocessing

- Features and target were split using `train_test_split`.
- Standardization applied using `StandardScaler`.

## Models Used

Trained and evaluated the following models:

- **Random Forest Classifier**
- **Logistic Regression**
- **Support Vector Machine (SVM)**
- **K-Nearest Neighbors (KNN)**

## Evaluation Metrics

- **Accuracy Score**
- **Confusion Matrix**
- **Classification Report** (Precision, Recall, F1-Score)

All models achieved **100% accuracy** on the test set.

## Visualization

- Bar plot comparing model accuracies.

## Requirements

- Python 3.x
- pandas
- numpy
- seaborn
- matplotlib
- scikit-learn

## Conclusion

All implemented models performed excellently on this dataset. This project highlights effective EDA, preprocessing, and multi-model evaluation in a classification setting.
